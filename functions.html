Functions

Functions package up code you want to reuse. Give them a name, some inputs, and (optionally) a value to hand back.

declaring & calling a function

A function has a return type, a name, parameters in parentheses, and a body in braces.

functions-basic.cpp
int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(4, 9);
    std::cout << "4 + 9 = " << result << std::endl;
    return 0;
}
output
4 + 9 = 13

void functions

Use void when a function does something but doesn't need to hand back a value.

void-fn.cpp
void greet(std::string name) {
    std::cout << "Hello, " << name << "!" << std::endl;
}

default arguments

Give a parameter a fallback value — callers can omit it entirely.

defaults.cpp
double power(double base, int exponent = 2) {
    double result = 1;
    for (int i = 0; i < exponent; i++) result *= base;
    return result;
}

power(5);     // 25   (exponent defaults to 2)
power(2, 10); // 1024 (explicit exponent)

function overloading

Multiple functions can share a name if their parameter lists differ — the compiler picks the right one based on the arguments you pass.

overload.cpp
int multiply(int a, int b) { return a * b; }
double multiply(double a, double b) { return a * b; }

multiply(3, 4);      // calls the int version → 12
multiply(2.5, 2.0);  // calls the double version → 5.0

pass-by-value vs. pass-by-reference

By default, arguments are copied into the function. Add & to the parameter type to let the function modify the caller's original variable.

by-reference.cpp
void doubleIt(int x) {        // by value — copy only
    x *= 2;
}
void doubleItRef(int &x) {    // by reference — modifies original
    x *= 2;
}

int n = 5;
doubleIt(n);
std::cout << n << std::endl;    // 5 — unchanged

doubleItRef(n);
std::cout << n << std::endl;    // 10 — changed!
output
5
10
tip
Pass large objects (like a big std::string or std::vector) as const & when you don't need to modify them — you get the speed of a reference without the risk of the function changing your data.
