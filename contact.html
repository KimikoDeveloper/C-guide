Send a question, correction, or request for a new chapter. This form posts to contact-handler.php, which validates the fields server-side and stores the message.

how this works
Submitting posts your fields to contact-handler.php, which runs server-side PHP: it validates the name/email/message, appends the message to data/messages.json, and redirects back here with a status flag (?sent=1 or ?sent=0). This requires a PHP server — opening this file directly in a browser (file://) won't submit anywhere.
