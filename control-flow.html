If / Else & Switch

Control flow lets your program make decisions — running different code depending on whether a condition is true or false.

the if statement

If the condition in parentheses is true, the block runs. Otherwise it's skipped.

if-basic.cpp
int temperature = 85;

if (temperature > 80) {
    std::cout << "It's hot outside." << std::endl;
}
output
It's hot outside.

if / else if / else

Chain conditions to handle several cases. C++ checks them top to bottom and stops at the first true one.

if-else-chain.cpp
int score = 72;

if (score >= 90) {
    std::cout << "Grade: A" << std::endl;
} else if (score >= 80) {
    std::cout << "Grade: B" << std::endl;
} else if (score >= 70) {
    std::cout << "Grade: C" << std::endl;
} else {
    std::cout << "Grade: F" << std::endl;
}
output
Grade: C
tip
Order your conditions carefully. If the score >= 70 check were placed before score >= 90, every A-grade score would incorrectly stop at "C" first.

the ternary operator

A compact one-line if/else for simple cases: condition ? valueIfTrue : valueIfFalse.

ternary.cpp
int age = 16;
std::string status = (age >= 18) ? "adult" : "minor";
std::cout << status << std::endl;
output
minor

the switch statement

When you're comparing one variable against many exact values, switch is often clearer than a long else if chain.

switch.cpp
int day = 3;

switch (day) {
    case 1:
        std::cout << "Monday"; break;
    case 2:
        std::cout << "Tuesday"; break;
    case 3:
        std::cout << "Wednesday"; break;
    default:
        std::cout << "Unknown day";
}
output
Wednesday
common pitfall
Forgetting break; causes "fall-through" — execution continues into the next case regardless of whether it matches. Sometimes intentional, usually a bug.
