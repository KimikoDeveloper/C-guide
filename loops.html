Loops

Loops repeat a block of code — so you don't have to write the same lines over and over.

the for loop

Best when you know how many times you want to repeat. Three parts, separated by semicolons: initialize, condition, update.

for-loop.cpp
for (int i = 1; i <= 5; i++) {
    std::cout << "Count: " << i << std::endl;
}
output
Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
tip
i is scoped to the loop — it only exists inside those braces. Reading it after the loop ends is a compile error.

the while loop

Best when you don't know the exact number of iterations ahead of time — it keeps going as long as the condition stays true.

while-loop.cpp
int countdown = 3;

while (countdown > 0) {
    std::cout << countdown << "..." << std::endl;
    countdown--;
}
std::cout << "Liftoff!" << std::endl;
output
3...
2...
1...
Liftoff!
common pitfall
If nothing inside the loop changes the condition, you get an infinite loop. Always make sure the loop variable actually moves toward the exit condition.

the do-while loop

Like while, but the condition is checked after the block runs — so the body always executes at least once.

do-while.cpp
int input;
do {
    std::cout << "Enter a positive number: ";
    std::cin >> input;
} while (input <= 0);

nested loops

A loop inside a loop — common for grids, tables, and 2D data.

nested.cpp
for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 3; col++) {
        std::cout << row * col << " ";
    }
    std::cout << std::endl;
}
output
1 2 3
2 4 6
3 6 9

break & continue

break

Exits the loop immediately, skipping any remaining iterations.

continue

Skips the rest of the current iteration and moves to the next one.

break-continue.cpp
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;  // skip even numbers
    if (i > 7) break;         // stop once i exceeds 7
    std::cout << i << " ";
}
output
1 3 5 7
