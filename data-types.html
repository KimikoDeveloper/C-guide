Data Types

Every variable in C++ has a type, fixed at compile time. The type determines how much memory it takes and what you can do with it.

the fundamental types

These seven cover the vast majority of everyday C++ code.

typeholdstypical sizeexample
intwhole numbers4 bytesint age = 30;
doubledecimal numbers (high precision)8 bytesdouble pi = 3.14159;
floatdecimal numbers (lower precision)4 bytesfloat ratio = 1.5f;
chara single character1 bytechar grade = 'A';
booltrue or false1 bytebool isOn = true;
std::stringtext (a sequence of chars)variesstd::string name = "Ada";
autocompiler infers the type—auto count = 5;

Sizes are typical on common 64-bit platforms, not guaranteed by the language — use sizeof(type) if you need the exact size on your system.

declaring & initializing variables

Declare a variable by writing its type, then its name. Give it a starting value with =.

variables.cpp
#include <iostream>
#include <string>

int main() {
    int age = 30;
    double price = 19.99;
    char initial = 'A';
    bool inStock = true;
    std::string name = "Widget";

    std::cout << name << " ($" << price << ") — age code: "
              << initial << ", in stock: " << inStock << std::endl;
    return 0;
}
output
Widget ($19.99) — age code: A, in stock: 1
tip
bool values print as 1 (true) or 0 (false) by default. Use std::boolalpha before printing if you want the words "true"/"false" instead.

constants

Use const when a value should never change after it's set — the compiler will enforce it for you.

constants.cpp
const double PI = 3.14159;
const int MAX_USERS = 100;

// PI = 3.14; // compile error — cannot assign to a const variable

type conversion

C++ converts between types automatically in some cases (implicit) and lets you force it in others (explicit, or "casting").

implicit conversion

Happens automatically, e.g. mixing int and double in one expression. C++ widens the int to a double before doing the math.

explicit conversion (casting)

You request it directly with static_cast<type>(value) — the modern, safer alternative to old C-style casts like (int)value.

conversion.cpp
int total = 7;
int count = 2;

// integer division truncates: 7 / 2 == 3, not 3.5
double wrong = total / count;              // 3.0

// cast one operand to double first to get real division
double correct = static_cast<double>(total) / count; // 3.5
common pitfall
Dividing two ints always produces an int — the fractional part is discarded, not rounded. This is one of the most common sources of subtle bugs for C++ beginners.
try it yourself

Declare an int called seconds set to 150. Convert it to minutes and remaining seconds using integer division (/) and the modulo operator (%), then print "2 min 30 sec". You'll meet % properly in the next chapter — give it a guess first.
