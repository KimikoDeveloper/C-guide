Operators

Operators combine values into new values. C++ groups them into a few families — arithmetic, assignment, comparison, logical, and increment/decrement.

arithmetic operators

operatormeaningexampleresult
+addition5 + 27
-subtraction5 - 23
*multiplication5 * 210
/division5 / 22 (int division truncates)
%modulo (remainder)5 % 21
arithmetic.cpp
int a = 17, b = 5;

std::cout << "sum: "  << (a + b) << std::endl;  // 22
std::cout << "quot: " << (a / b) << std::endl;  // 3
std::cout << "rem: "  << (a % b) << std::endl;  // 2
output
sum: 22
quot: 3
rem: 2
tip
% only works on integer types. It's the standard way to check things like "is this number even" (n % 2 == 0) or to wrap a value into a range.

assignment operators

Shorthand for "do the operation, then assign the result back to the same variable."

operatorequivalent to
x += 5x = x + 5
x -= 5x = x - 5
x *= 5x = x * 5
x /= 5x = x / 5
x %= 5x = x % 5

comparison operators

These always produce a bool — true or false.

operatormeaning
==equal to
!=not equal to
> / <greater / less than
>= / <=greater-or-equal / less-or-equal
common pitfall
= assigns; == compares. Writing if (x = 5) instead of if (x == 5) compiles, silently sets x to 5, and is always true — a classic beginner bug.

logical.cpp
int age = 20;
bool hasTicket = true;

if (age >= 18 && hasTicket) {
    std::cout << "Entry allowed" << std::endl;
}
output
Entry allowed

increment & decrement

++ and -- add or subtract 1. Placement changes when the value updates.

prefix: ++x

Increments first, then returns the new value. int y = ++x; — both x and y get the incremented value.

postfix: x++

Returns the current value first, then increments. int y = x++; — y gets the old value, x is incremented after.

operator precedence

Like math class: multiplication/division before addition/subtraction. When unsure, use parentheses — they cost nothing and remove all ambiguity.

precedence.cpp
int result = 2 + 3 * 4;      // 14, not 20 — * runs first
int clearer = 2 + (3 * 4);  // same result, easier to read
try it yourself

Write an expression that checks whether a year is a leap year: divisible by 4, but not by 100 unless it's also divisible by 400. You'll need %, &&, ||, and parentheses.
