Arrays & Strings

Arrays hold a fixed-size sequence of same-typed values. Strings are, under the hood, sequences of characters with a lot of built-in convenience.

fixed-size arrays

Declared with a type, a name, and a size in brackets. Indexing starts at 0.

arrays-basic.cpp
int scores[5] = {90, 85, 77, 92, 88};

std::cout << "First score: " << scores[0] << std::endl;
std::cout << "Last score: "  << scores[4] << std::endl;

for (int i = 0; i < 5; i++) {
    std::cout << scores[i] << " ";
}
output
First score: 90
Last score: 88
90 85 77 92 88
common pitfall
A 5-element array has valid indices 0 through 4. Accessing scores[5] reads memory outside the array — C++ won't stop you, and the result is undefined behavior, not a helpful error.

2D arrays

An array of arrays — useful for grids, boards, and tables.

2d-array.cpp
int grid[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

std::cout << grid[1][2] << std::endl; // 6 — row 1, column 2

std::string

Include <string> and you get concatenation, length, substrings, and comparisons for free — far friendlier than raw C-style char arrays.

strings.cpp
#include <string>

std::string first = "Ada";
std::string last  = "Lovelace";
std::string full  = first + " " + last;   // concatenation with +

std::cout << full << std::endl;
std::cout << "length: " << full.length() << std::endl;
std::cout << "first 3 chars: " << full.substr(0, 3) << std::endl;
output
Ada Lovelace
length: 12
first 3 chars: Ada

std::vector — a resizable array

Regular arrays have a fixed size decided at compile time. std::vector (from <vector>) can grow and shrink at runtime.

vector.cpp
#include <vector>

std::vector<int> nums = {10, 20, 30};
nums.push_back(40);    // add to the end

for (int n : nums) {       // range-based for loop
    std::cout << n << " ";
}
std::cout << "\nsize: " << nums.size() << std::endl;
output
10 20 30 40 
size: 4
tip
The for (int n : nums) syntax is a range-based for loop — it reads "for each n in nums," and avoids manual index bookkeeping entirely.
try it yourself

Given std::vector<int> nums = {4, 8, 15, 16, 23, 42};, write a loop that computes and prints the sum and the average of all elements.
